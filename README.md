# Тренажёр переговоров

Веб-приложение для обучения базовым навыкам деловых переговоров в интерактивном формате.

Пользователь проходит учебные сценарии, принимает решения в ходе диалога и видит, как выбранные ответы влияют на дальнейшее развитие ситуации.

Основная цель проекта — помочь начинающим освоить базовые приёмы переговоров и применить их на практике в безопасной учебной среде.

В тренажёре предусмотрены:

* краткая теория;
* практические ситуации;
* ветвящиеся сценарии;
* несколько вариантов решений;
* пояснения и обратная связь по ответам.
