# Реализованные изменения

## Сценарии и penalty

- Канонический формат сценария переведён на `schemaVersion: 3`.
- Реакция хранит только `penalty: 0 | 1 | 2` и `feedback`; дублирующие grade/assessment/critical-error поля удалены из рабочего формата.
- В Maker оценки отображаются как `Уместная (0)`, `Сомнительная (+1)`, `Нежелательная (+2)`.
- Настройка досрочного завершения хранится в `settings.penalty`: `enabled`, `threshold`, `failureEndingId`.
- Явный `reaction.endingId` имеет приоритет над общим penalty-финалом.
- Добавлен анализатор достижимых penalty-состояний графа с вычислением диапазона и рекомендаций `Строго / Рекомендуемый / Мягко`.
- Недостижимый включённый threshold блокирует публикацию; слишком строгие/мягкие значения дают предупреждения.
- Старые schemaVersion 2 / Arena JSON импортируются через слой совместимости и преобразуются в v3.

## Опубликованные сценарии

- Обновлён сценарий `Переговоры об условиях работы`.
- Добавлен сценарий `Срыв срока: сохранение зарплаты и условий`.
- Seed публикует оба сценария идемпотентно и не создаёт лишних версий при повторном запуске.

## Maker

- Реплики и финалы в левой панели сворачиваются независимо.
- Поиск реплик сохраняется при сворачивании.
- Убраны секция «Дополнительно», отдельный grade/penalty UI, критическая ошибка и устаревший поясняющий текст.
- Добавлена компактная настройка penalty с анализом графа, пресетами и ручным threshold.

## Профиль

- История: 10 записей на страницу.
- Достижения: 3 на страницу.
- Навыки: 4 на страницу, чтобы визуальная высота совпадала с блоком из трёх достижений.
- Блоки навыков и достижений растягиваются до одинаковой высоты.
- Пагинация использует тот же визуальный паттерн, что и пагинация отзывов в админке.

## Кроссбраузерность

- Скрыт нативный Edge password reveal (`::-ms-reveal` / `::-ms-clear`), чтобы не появлялись два глазка рядом с собственной кнопкой.
- Для password input/button добавлен согласованный `appearance` для Chromium/WebKit.

## Проверки

На текущем исходном коде успешно проходят:

- `tsc --noEmit` — без ошибок.
- `npm run test:logic` — 40/40 тестов.
- `npm run test:api:embedded` — 21/21 тестов.

Production Vite build в текущем Linux-окружении не запускался до конца, потому что исходный архив содержит Windows-native `node_modules` (`@rolldown/binding-win32-x64-msvc`, Windows TypeScript binding) и не содержит Linux binding. Это ограничение приложенных зависимостей, а не TypeScript-ошибка проекта. Итоговый архив специально не содержит `node_modules`; на Windows следует выполнить `npm ci` перед запуском/сборкой.

Дополнительно перед упаковкой оба встроенных сценария были сверены с переданными JSON по ID узлов, текстам, вариантам текста, реакциям, примерам, `penalty`, `feedback` и финалам. Расхождений содержимого не обнаружено; изменены только формат настроек penalty и выбранные threshold согласно новой модели.
