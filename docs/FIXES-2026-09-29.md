# Исправления интерфейса и управления сценариями

Основа: приложенный архив `Cool-Peppers-main.zip` от 29 сентября 2026 года.

## Что исправлено

1. **Рекомендуемый диапазон досрочного завершения.** Верхняя граница округляется вверх. Для сценария «Срыв срока: сохранение зарплаты и условий» диапазон теперь **3–4**. Расчёт учитывает только достижимые лимиты, при которых остаётся путь к обычному финалу. Максимум 7 в карточке включает штраф последней реакции, а максимум для системного завершения равен 5: явно заданный финал реакции имеет приоритет. Рекомендуемая полоса составляет 50–75% этого второго максимума с округлением обеих границ вверх.
2. **Оценка реакции.** Скрытые радиополя располагаются внутри своих карточек и больше не перемещают прокрутку при выборе. Управление с клавиатуры и видимый фокус сохранены. В узкой панели варианты идут строками, в широкой — тремя карточками; длинный текст помещается внутри.
3. **Достижения.** Выше 620 px — шесть карточек на странице, две колонки по три; до 620 px включительно — три карточки в одной колонке. Размеры текста: заголовок 16 px, описание 14 px, прогресс 13 px. У заблокированных достижений убрано общее снижение непрозрачности, ухудшавшее читаемость. Пагинация учитывает изменение ширины окна.
4. **Опубликованные сценарии в управлении.** В список добавлены общие опубликованные сценарии без владельца, включая встроенные. Даже при отсутствии черновика их можно открыть, сохранить и опубликовать новой версией. Личные сценарии другого администратора остаются доступны их владельцу. Повторный seed не заменяет сохранённые администратором изменения и не восстанавливает архивные или удалённые сценарии.

## Применение патча

Положите `Cool-Peppers-ui-scenarios-fixes.patch` в корень существующего проекта и выполните в PowerShell:

```powershell
git apply --check .\Cool-Peppers-ui-scenarios-fixes.patch
git apply .\Cool-Peppers-ui-scenarios-fixes.patch
```

Если проверка сообщает о несовпадении файлов, не применяйте патч принудительно: он рассчитан на приложенную версию проекта. В полном ZIP исправления уже внесены, повторно применять патч к нему не требуется.

Для Docker пересоберите приложение:

```powershell
docker compose up -d --build
```

При локальном запуске остановите работающий процесс и запустите `npm run dev` заново. Для production выполните `npm run build`, затем `npm start`.

Новых зависимостей и миграций нет. Пересоздавать базу, удалять Docker volume или запускать `db:setup` для этих исправлений не требуется. Для чистой распаковки архива сначала установите зависимости через `npm ci` и настройте существующее подключение к базе по основному README.

## Проверка

- TypeScript и production-сборка.
- Тесты логики, включая границы 3–4 и достижимость рекомендованных лимитов.
- API на временной PGlite: просмотр встроенных сценариев, права доступа, создание черновика при сохранении, конфликт редакций, публикация и сохранность изменений после seed. PGlite не проверяет TCP-подключение, роли PostgreSQL и реальную конкуренцию блокировок.
- Chromium: пагинация и вёрстка достижений на ширинах 320, 390, 620, 621, 1440 и 1920 px; сохранение прокрутки при выборе оценки мышью и клавиатурой; узкая и широкая панель свойств; открытие встроенного сценария из управления.

Целевые браузерные проверки находятся в `tests/requested-fixes.spec.ts`.
