# Проверка версии 0.4.0

Проверено 21 сентября 2026 года на исходниках этого архива.

| Проверка                    | Результат                                                                  |
| --------------------------- | -------------------------------------------------------------------------- |
| TypeScript                  | Клиент, сервер и тесты компилируются без ошибок                            |
| Production build            | SPA успешно собирается; maker загружается отдельным chunk                  |
| `npm run test:logic`        | 16 тестов, включая все 180 маршрутов старого сценария до и после адаптации |
| `npm run test:api:embedded` | 13 интеграционных сценариев + родительский тест на PGlite                  |
| Playwright                  | 11 браузерных сценариев: 9 существующих и 2 для maker                      |
| Визуальная проверка         | Скриншоты maker на 1440×950 и 390×844; адаптивное полотно и Inspector      |

Проверены сохранение незавершённого графа, отказ публикации при ошибках, отдельное сохранение `editor`, перетаскивание точки реакции в пустое место, создание финала с автоматической связью и фокусом текста, движение карточек без изменения definition, восстановление после загрузки, тестовое прохождение без записи попытки, публикация и настоящий игровой результат.

Также проверены дублирование с новыми ID, удаление, undo/redo, предупреждения о недостижимых блоках, редактирование intent/examples и отсутствие примеров в интерфейсе игрока. Для старых сценариев проверены сохранность всех переходов, контекстных реплик, штрафов, истории и финалов. Новый сценарий проходит без старой оценки.

Существующие API-проверки включают права администратора, изоляцию личных данных, 409 при конфликте ревизий, повторную отправку ответа, неизменяемость опубликованных версий и сохранение старой версии в начатой попытке.

## Условия проверки

Использовались Node.js 24 и Chromium 153. SQL/API и браузерные проверки выполнялись с настоящим PostgreSQL-движком в WebAssembly (PGlite), а не с подменёнными ответами HTTP. Тестовый адаптер находится в `tests/support/`; рабочее приложение по-прежнему использует `pg.Pool` и отдельный PostgreSQL.

PGlite сериализует операции одного движка. Поэтому здесь не проверены конкурентные блокировки независимых PostgreSQL-соединений, TCP/SCRAM, права ролей, TLS, Docker Desktop и непосредственный запуск на Windows. Для этого предусмотрен `npm run test:api` с `TEST_DATABASE_URL`; инструкция — в README. Миграция 002 применена и повторно проверена вместе с исходной миграцией; контрольная сумма 001 не менялась.

Ограничения MVP и формат данных описаны в `docs/MAKER.md`.
