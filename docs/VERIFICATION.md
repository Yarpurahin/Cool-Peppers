# Проверка проекта

Основные команды:

```bash
npm run typecheck
npm run test:logic
npm run test:api
npm run test:ui
npm run build
```

Что покрывается тестами:

- компиляция и прохождение канонического `MakerDefinition`;
- все ветки встроенного сценария;
- контекстные варианты реплик;
- штрафы, финалы и циклы с выходом;
- maker, импорт старых JSON и нормализация evaluation;
- маршрутизация связей на полотне;
- PostgreSQL API, авторизация, публикация, геймификация и достижения;
- browser flow основных пользовательских экранов.

Для проверки миграции старых документов на существующей БД:

```bash
npm run db:normalize-scenarios
```

Повторный запуск должен быть идемпотентным: уже канонические документы не изменяются.
