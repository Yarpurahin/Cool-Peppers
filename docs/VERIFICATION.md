# Проверка интерфейса

Проверено 17 сентября 2026 года. Среда: Node.js 24.19.0, Linux, Chromium 153, Playwright 1.63.0. Проверка касается интерфейса; модель переговоров и сервер в этот проект не подключены.

## Выполнено

- Итоговый запуск: **12 браузерных проверок пройдены**, ошибок нет. Внутри пяти проверок адаптивности проверены 100 сочетаний адреса и ширины.
- Строгая проверка TypeScript и production-сборка Vite.
- Браузерные проверки Playwright: 20 прямых адресов на ширинах 320, 390, 768, 1024 и 1440 px — 100 сочетаний маршрута и ширины.
- Все страницы имеют один основной заголовок и один `main`; отсутствуют горизонтальная прокрутка, сломанные изображения и ошибки JavaScript/консоли на проверенных маршрутах.
- SPA-переходы сохраняют документ. «Назад/Вперёд» возвращают страницу и фильтры каталога.
- Поиск, сочетание фильтров, пустая выдача и сброс.
- Несовпадение паролей, показ/скрытие пароля, уведомления заглушек регистрации/входа; нет отправки POST с форм.
- Выбор реплики не продвигает переговоры. Переход к разбору явно открывает статический пример.
- Открытие мобильного меню, Escape, закрытие после перехода и возврат фокуса из уведомления.
- Вкладки редактора, стрелки клавиатуры, выбор вопроса и уведомление об отсутствии сохранения.
- Выравнивание нижних границ карточки собеседника и блока с советом при ширине 1440 px.
- Удаление указанных в задании блоков; на страницах ошибок в основном содержимом одно действие «На главную».
- Сняты и просмотрены экраны настольной и мобильной версии. Во время проверки исправлен перенос заголовка регистрации на узком экране.

## Ограничения

- Проверена эмуляция размеров экрана в Chromium. Физические телефоны, Safari/iOS и Firefox отдельно не проверялись.
- Проверка клавиатурного управления не заменяет полный аудит доступности со скринридером.
- Реальной авторизации, хранения данных, прохождения и оценки переговоров нет; их корректность этим прогоном не заявляется.
- Развёртывание на Nginx/Vercel/Netlify и установка на Windows здесь не выполнялись. Инструкции и конфигурации приложены.

## Повторить проверку

```bash
npm ci
npx playwright install chromium
npm run build
npm run test:ui
```

Исходники проверок: `tests/interface.spec.ts`. Скриншоты и трассировки при ошибках автоматически попадают в `test-results/`.

## Исправление запуска в 0.2.1

Причина белого экрана воспроизведена в отдельной копии: после последовательной распаковки старого JavaScript-архива и React-архива браузер загружал `src/data/scenarios.js` и сообщал об отсутствии `findScenario`. В исходных данных TypeScript нужная функция присутствовала.

Относительные импорты изменены на явные `.ts`/`.tsx`. После обновления успешно проверен запуск через dev-сервер в той же копии с сохранёнными старыми JavaScript-файлами: главная, профиль, превью сценария, диалог и редактор. Ошибок загрузки модулей нет. Проверка TypeScript и production-сборка также прошли. Файлы пользователя автоматически не удаляются.
