# Геймификация

Геймификация строится поверх реальных завершённых попыток и не требует специального кода для каждого сценария. Сценарий сообщает сложность, навык и тип финала, а сервер рассчитывает награду и сохраняет её один раз на попытку.

## Награда за прохождение

Базовый XP зависит от сложности: `easy` — 100, `medium` — 125, `hard` — 150. Тип финала даёт множитель: `success` — 100%, `neutral` — 75%, `failure` — 50%. Каждый штрафной балл уменьшает награду на 5 XP. Завершённая тренировка всё равно даёт положительный прогресс.

Повторная практика защищена от фарма:

- первое завершение сценария — 100% рассчитанной награды;
- ранее не открытая концовка этого сценария — 100%;
- повтор уже открытой концовки — 35%.

Та же логика применяется к XP навыка. На экране результата пользователь видит расшифровку: базовую награду, множитель финала, штраф и, если применён, коэффициент повторного прохождения.

## Уровни, навыки и мастерство

Общий уровень вычисляется из суммарного XP, поэтому не хранится как отдельный источник истины. На странице профиля показываются текущий уровень, прогресс до следующего, суммарный XP и недельная цель из трёх завершённых тренировок.

`metadata.skill` опубликованного сценария определяет прокачиваемый навык. Поэтому новые сценарии, включая импортированные JSON-файлы, автоматически участвуют в геймификации.

За каждый сценарий хранится лучший показатель мастерства:

- 1 звезда — сценарий завершён с неуспешным финалом;
- 2 звезды — успешный/нейтральный итог либо успешный итог с заметными штрафами;
- 3 звезды — успешный итог с 0–1 штрафным баллом.

## Достижения

Достижения описываются записями в `achievements`, а полученные награды — в `user_achievements`. Активные достижения проверяются по всей накопленной истории, поэтому новое правило может выдаться пользователю ретроактивно.

Администратор управляет ими на `/admin/achievements`: создаёт и редактирует правила, выбирает иконку, условие и целевое значение, активирует или отправляет достижение в архив. Произвольный JavaScript или JSON-условия не принимаются; доступны безопасные типы:

- число завершённых тренировок;
- число успешных исходов;
- прохождения без штрафов;
- успешные прохождения выбранной сложности;
- количество трёхзвёздочных прохождений;
- число разных концовок одного сценария;
- число тренировок одного навыка;
- число различных завершённых сценариев;
- достижение глобального уровня.

Удаления нет намеренно. Архивное достижение больше не выдаётся новым пользователям, но уже получившие его сохраняют награду и видят её в профиле. Для незакрытых активных достижений показывается прогресс `текущее / цель`.

## Данные

Миграция `006_gamification.sql` создаёт:

- `attempt_rewards` — неизменяемая награда за завершённую попытку;
- `achievements` — настройки достижений;
- `user_achievements` — факты получения.

Ограничение `attempt_rewards.attempt_id PRIMARY KEY` предотвращает повторное начисление XP при повторной отправке уже обработанного ответа. Миграция также восстанавливает награды для существующих завершённых graph-сценариев и выдаёт стандартные достижения по уже накопленной истории.
