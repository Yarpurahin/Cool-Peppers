# Интерфейс прохождения

Первый патч — самостоятельный этап: работает без движка сценария и без хранилища.
`PlayPage` и `ResultPage` адаптируют существующие демонстрационные данные.

- `src/features/negotiation/ui/types.ts` — контракты отображения и события формы.
- `PlayView` — реплика, подтверждение ответа, история, этапы, цель и роль.
- `ResultView` — итог, показатель, следующий шаг и разбор выбранных реплик.
- `FeedbackForm` — независимая форма отзыва; сохранение передаётся через callback.
- `negotiation.css` — адаптивные стили на основе токенов проекта и PDF-макета.

Компоненты получают данные через props. Они не знают о переходах, штрафах,
localStorage или сервере. Радиокнопки доступны с клавиатуры; после смены
вопроса фокус переходит на новую реплику. На мобильных устройствах остаются
основной диалог, цель и роль, как в макете.

Второй патч применяется поверх первого и заменяет демонстрационные адаптеры
подключением настоящего прохождения. Сам UI не требует переписывания.
