# UI прохождения сценария

Экран прохождения и экран результата получают один и тот же канонический `MakerDefinition`, привязанный к версии попытки.

- `PlayPage` отображает текущую реплику и `reactions`.
- `ResultPage` строит разбор по подтверждённой истории.
- `presentation.ts` является единственной презентационной проекцией движка.
- Реальная попытка хранится на сервере, а не в браузерном `localStorage`.
- `feedbackMode=immediate` показывает оценку реакции после ответа; `summary` переносит её в итоговый разбор; `hidden` учитывает оценку без показа участнику.

Демонстрационных Play/Result-страниц и отдельного demo-провайдера в рабочем приложении больше нет.
