# Интерфейс прохождения — версия 0.3.0

`PlayPage` и `ResultPage` загружают сохранённые попытки через
`NegotiationProvider`. Каталог и аккаунт поступают из `DataProvider`.

- `PlayView` получает готовую модель отображения и события. Во время запроса
  отправка и выбор ответа блокируются; при ошибке вопрос остаётся прежним.
- `ResultView` показывает рассчитанный результат конкретной попытки и её версии.
- `FeedbackForm` поддерживает асинхронный callback, индикатор занятости и ошибки.
- `AttemptPage` позволяет просмотреть конкретную старую попытку из профиля.
- `DemoPlayPage` и `DemoResultPage` отображают два исходных демонстрационных
  сценария без вымышленных реальных результатов.

Компоненты отображения не обращаются к базе напрямую. Радиокнопки доступны
с клавиатуры; после смены вопроса фокус переходит на новую реплику. Стили
и адаптивная компоновка исходного проекта сохранены.

Источники данных и запуск описаны в [README](../README.md).
