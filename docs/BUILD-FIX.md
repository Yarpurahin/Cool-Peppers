# Исправление сборки — 28.09.2026

Основа: последняя версия `Cool-Peppers-canonical-runtime.zip`. Переход на канонический `MakerDefinition`, оценки реакций и существующие функции сохранены.

## Исправления

- История незавершённой попытки показывает `row.reaction.label`. Ключи строк учитывают номер шага, поэтому повторное посещение одного узла не создаёт одинаковые ключи React.
- В комплекте отсутствуют старые `DemoPlayPage.tsx`, `DemoResultPage.tsx`, `DemoProvider.tsx` и их импорты. Рабочие маршруты используют API и актуальный движок.
- Разбор и сохранение документа проверяют его структуру, допускают пустые поля черновика и незавершённые переходы. Полная проверка графа выполняется перед публикацией и проигрыванием.
- Нормализация документов при старте допускает незавершённые черновики. Проверены сохранение графа, позиций, ревизии и повторный запуск без изменений.
- Восстановлен `.env.example`. Основной Compose не публикует порт PostgreSQL, поэтому не конфликтует с занятыми портами 5432/5433 в Windows. Доступ с хоста включается отдельным `compose.db-port.yaml`.
- Имя Compose-проекта закреплено как `cool-peppers`; имя тома с базой остаётся `cool_peppers_postgres`. SQL-миграции не изменены.
- Исправлена проверка публикации в существующем API-тесте: цикл с выходом допустим, отсутствующий узел назначения должен блокировать публикацию.

## Выполненная проверка

- Чистая установка зависимостей через `npm ci`.
- `npm run build`: TypeScript, сборка Vite и генерация HTML страниц `/about` и `/feedback`.
- `npm run test:logic`: 35 проверок, включая все 180 путей встроенного сценария.

## Как обновить

Распакуйте ZIP в отдельную пустую папку. Копирование поверх старых исходников не удаляет устаревшие демо-файлы. Остановите прежние контейнеры командой `docker compose down` без `-v`, перенесите прежний `.env` в новую папку и выполните `docker compose up --build -d`.

При существующей базе сохраняйте её текущие имя пользователя и пароль. Изменение `POSTGRES_PASSWORD` в `.env` не меняет пароль внутри уже созданного тома. Инструкция для первой установки и необязательного доступа через pgAdmin находится в README.
